# BookStore Online — React Native Flexbox

Project tong hop dung theo PDF bai tap: Gio 1 + Gio 2 + Gio 3.

## Chay project

```bash
npm install
npm run typecheck
npx expo start
```

Sau do chon Android/iOS/Web theo moi truong cua ban.

## Doi chieu voi de

- Header nam ngoai ScrollView de dung yen khi cuon.
- CategoryChips dung flexDirection row + flexWrap + gap.
- BookGrid dung flexDirection row + flexWrap + width 48% + space-between.
- Anh bia dung aspectRatio 3/4.
- DiscountBadge dung position absolute, top 6, left 6, neo vao View relative.
- FloatingCartButton dung position absolute, bottom 24, right 20; badge so luong la absolute ben trong nut.
- `content.paddingBottom = 100` de nut gio khong che sach cuoi.
